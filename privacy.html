Local processing in SamplePilot

SamplePilot reads the default output device, supported sample-rate ranges, physical audio formats and available audio-process activity information. In Music metadata modes, it reads the playing track’s identifier, title, reported sample rate and available file location through macOS automation. It can read format metadata from a file selected by you or otherwise accessible through macOS.

This information is processed on your Mac. The app does not upload audio, track metadata, file locations or device information to the developer. It does not record audio, use a microphone, access private player APIs, include analytics or advertising, or operate an account or cloud service.

Trial and in-app purchases

Apple’s StoreKit handles the free trial activation, payment, purchase history and restoration. SamplePilot locally verifies matching StoreKit transactions and uses the trial’s original activation date to calculate its 14-day duration. Apple processes purchases under its own policies; the developer does not receive your payment details or Apple Account password. SamplePilot does not send transaction identifiers or purchase history to a developer-operated server.

A last-observed-time anchor is saved only in local preferences to reduce simple clock rollback. The app does not directly access Keychain or ask for a Keychain password. Test and production environments use separate storage. Local settings cannot grant a full-version purchase. Removing app preferences does not revoke or reset purchases recorded by Apple.

Settings and access

Automatic switching preferences, bit-depth selection and Music metadata options are stored locally in the app’s preferences. File selections and source mode are session-only; SamplePilot does not store security-scoped bookmarks or a listening history. Diagnostic text remains in memory in the diagnostics window. Closing the app clears that session information; local preferences remain until the app’s data is removed.

Music automation is optional and can be managed in System Settings → Privacy & Security → Automation. File access is read-only and limited by macOS sandbox permissions. No general Music-folder, Downloads, microphone, recording or network permission is requested.

Support messages

If you email support, the developer receives your address, message and any details you choose to include. These are used to answer your request and address the issue. Processing is based on handling a requested service or on the legitimate interest in responding to enquiries, as applicable. Correspondence is retained only as long as needed to handle the request or meet applicable retention obligations. Do not send audio files or private metadata unless needed and intentionally shared.

This website

The supplied website contains no analytics, cookies, embedded external media or third-party fonts. When hosted online, the hosting provider processes technical connection information needed to deliver pages, such as IP addresses and request information. If you visit a GitHub Pages deployment, GitHub acts as the hosting provider; see GitHub’s Privacy Statement. Hosting-related processing supports delivery and security of the website. If the hosting provider changes, this section will be updated.

Apple services

App Store downloads, optional Apple diagnostics and Apple Music are provided by Apple under Apple’s own policies. They are separate from SamplePilot’s local processing.
