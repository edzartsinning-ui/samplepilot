Trial and purchase

Click the license status in the main view or Settings to open Trial & Purchase. Start the free 14-day Trial after reviewing the duration, the features locked after expiry and the one-time unlock price. The trial begins when Apple confirms activation. It does not renew or charge you automatically.

After 14 full days, output monitoring, known routes, device formats, read-only diagnostics and help remain available. Automatic and manual audio changes and write diagnostics require the separate permanent Full Unlock. Use Restore Purchases with the same Apple Account to restore a purchase or the trial’s original activation; restoring does not restart a trial. Cancelled, pending or unverified purchases do not unlock features.

Getting started

  1. Open SamplePilot and click its menu bar item. The app runs without a Dock icon.
  2. Start the free trial or unlock the full version to enable audio changes.
  3. Select Background detection. Allow optional Apple Music automation when using Music metadata.
  4. For a local file reference, select Audio file reference and choose a file. For another player, a manual output rate can also be used.
  5. Enable automatic switching. Only supported device formats are requested.
  6. Use Settings to opt in to unverified Music stream metadata, or enable launch at login from the main view.

Source compatibility

Other audio appsDetect Core Audio process activity where available. Original track format and automatic track switching are not universally available.
Selected audio filesRead supported file metadata as a reference. Selection does not start playback or follow another player’s playlist.
Manual referenceChoose Manual output rate, select or enter a rate in Hz, and click Apply rate now. This sets a supported output rate for any player using the default system output.

Why does the bit depth differ?

The physical DAC format may be 32-bit even when the original track is 16-bit or 24-bit. This does not add information to the source. AAC/MP3 bitrates do not establish original bit depth. Float formats are labelled explicitly.

No change or access denied?

Check the default macOS output in Audio MIDI Setup. Bluetooth and AirPlay devices may have fixed formats. A player routed to a separate device may bypass the default output used by SamplePilot. Allow Music automation in System Settings → Privacy & Security → Automation if you use that mode.

File access is limited to files you explicitly select and any access macOS grants for a Music file reference. Unreadable or protected files show unknown depth. Select an accessible audio file to use the file-reference workflow.

Core Audio diagnostics

In Settings, open Core Audio Diagnostics. Start with the read-only check. The write test temporarily changes supported rates and attempts to restore the original rate and physical formats. Stop playback first. If the output device changes, the test stops and may require a manual restore on the original device. Actual sandbox behavior must be checked with a signed sandboxed build.

Contacting support

Include your macOS version, SamplePilot version, audio interface model, source mode and the exact status message. Diagnostic reports stay in the app until you copy and send them. Remove device identifiers, private file names or other details you do not want to share.
